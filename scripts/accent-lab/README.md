# Accent Lab — Pronunciation Script Series (EEC)

Ready-to-record scripts for the **Accent Lab** Shorts series, targeting the
pronunciation mistakes Arabic speakers make most in English. Premium PDF layout
(charcoal + gold, RTL-correct), hook-first, Egyptian Arabic, EEC brand voice.

Content is research-informed: educational Shorts retain best at ~30–40s with a
kinetic first-3-second hook; each script gives the movement cue, the problem
(with wrong→right pairs), the fix + a physical technique, a drill, a comment CTA,
on-screen text cues, and a suggested YouTube title.

## Episodes
1. **P vs B** — "Bebsi vs Pepsi" (no /p/ in Arabic; aspiration + paper test)
2. **F vs V** — throat vibration (hand-on-neck test)
3. **TH** — tongue between the teeth (mirror test)
4. **American R** — retroflex; tongue touches nothing
5. **Consonant clusters** — no added vowel ("school" not "ischool")
6. **Short vs long vowels** — ship vs sheep

## Files
- `AccentLab_ALL_EPISODES.pdf` — full series (cover + 6 episodes + production notes)
- `AccentLab_0X_*.pdf` — one file per episode
- `_generate.py` — regenerates the HTML; render with headless Chrome
  (`--print-to-pdf`). Uses Cairo + Inter web fonts, CSS symbols (no emoji) to
  avoid glyph issues in PDF.

## How to use
Record one episode at a time. Open on the HOOK with movement (no intro/logo
first — brand at the END). Show the physical technique close to camera. Burn
Arabic captions. Drop the finished clip in the watched Drive folder — the
publishing engine auto-writes title/description/hashtags/pinned comment
(see docs/PUBLISHING-STANDARD.md); optionally use the suggested title per script.

> Pronunciation facts verified against research and rephrased for compliance.
