# Accent Lab — Pronunciation Script Series (EEC)

Ready-to-record scripts for the **Accent Lab** Shorts series, targeting the
pronunciation mistakes Arabic speakers make most in English. Hook-first,
Egyptian Arabic, in EEC brand voice. Each script includes: 3-second hook,
the problem, the fix + a physical technique, a quick drill, a CTA, on-screen
text cues, minimal pairs, and a suggested YouTube title.

## Episodes
1. **P vs B** — "Bebsi vs Pepsi" (no /p/ in Arabic; aspiration + paper test)
2. **F vs V** — throat vibration (hand-on-neck test)
3. **TH** — tongue between the teeth (mirror test)
4. **American R** — retroflex, tongue touches nothing
5. **Consonant clusters** — no added vowel ("school" not "ischool")
6. **Short vs long vowels** — ship vs sheep

## Files
- `AccentLab_ALL_EPISODES.pdf` — the full series in one file
- `AccentLab_0X_*.pdf` — one file per episode
- `_scripts_source.py` / `_generate_pdfs.py` — source (regenerate with PIL/raqm)

## How to use
Record one episode at a time. Open on the HOOK (no intro/logo first — brand at
the END). Show the physical technique close to camera. Burn Arabic captions.
Drop the finished clip in the watched Drive folder — the publishing engine
auto-generates title/description/hashtags/pinned comment (see
docs/PUBLISHING-STANDARD.md). Optionally override the title with the suggested
one in each script.

> Facts verified against pronunciation research; rephrased for compliance.
